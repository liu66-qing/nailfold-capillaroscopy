## 1 最小可判定效应量：BA 配对差 ≥ 0.05

这个数不是我选的偏好值，是从上一轮实测的配对 CI 宽度算出来的下限。
来源 `artifacts/experiments/medical_encoder_transfer_20260921/paired_summary.csv`，
21 个「臂 vs anchor」配对比较，n=162~185：

| 统计量 | BA 配对差的 CI 半宽 |
|---|---|
| 中位数（全部 21 个） | 0.0550 |
| 中位数（剔除塌缩字段 rbc_aggregation） | 0.0572 |
| p25 / p75 | 0.0510 / 0.0646 |
| 最小 / 最大 | 0.0394 / 0.0776 |
| CI 排除 0 的比例 | **2 / 21** |

也就是说在 n≈180 的病例数下，一个真实增益必须达到约 0.055 才有可能让 CI
离开 0。低于 0.05 的差值在本样本量上**与噪声不可区分**，不管它在表里
看起来多像改善。因此：

- **采用门槛（criterion 2 的实际数值）：BA 配对差 ≥ 0.05，且配对 CI 下界 > 0。**
- 0.02~0.05 记为 `below_resolution`，明确写成「本样本量测不出」，
  不写成「小幅提升」。
- < 0.02 记为 `no_effect`。
- 21 个比较里只有 2 个 CI 排除 0，这本身就是提醒：本轮大概率也是以 null 为主，
  不要把 null 解释成实验失败或去调阈值。

## 2 主要指标与次要指标（读结果前固定）

- 主要：accuracy − 单一常数答案基线 = delta；配对 BA 差 vs A0。
- 次要（同时报告，不用来替换主要判据）：BA、AUROC、逐类召回、混淆矩阵、
  bootstrap 95% CI、校准、拒答覆盖率/拒答后准确率。
- 基线必须是**单一众数答案**（development 模式），不是 class_weight=balanced。
- 唯一 OOF 键：`exam_case_id + field`，病例级分组。

## 3 每个字段的判定分类（只有这四种，不新增）

- `adopt`：8 条采用条件全部满足。
- `signal_only`：有区分力但不满足全部 8 条，不上线。
- `below_resolution`：差值 0.02~0.05，本样本量不可判定。
- `not_measurable`：塌缩单类、少数类不足、或该字段的单位不在静态单帧图内。

## 4 预先声明的失败模式（不构成「改进」）

看到下列情况必须记为塌缩或虚高，不得计入 adopt：

1. 预测塌缩到单一类别，即使 accuracy 上升。
2. accuracy 提升但基线也同步提升（患病率翻转造成的假增益，clarity 在
   locked 上已有先例：表面 +0.391，真实 +0.087）。
3. 只有 AUROC 动、accuracy 与 BA 都没动。
4. 三个档案 LOAO 中任意一个方向明显下降。
5. 多分类靠合并类别换来的提升（类别方案必须与 A0 完全相同）。

## 7 归因限制（结果出来之前就已经成立）

- **预算限制**：8.5 GB 上全骨干适配 ViT-L 实测 15.2 min/100 步（≈49 h），
  不可行。所以任何 null 只是「末 4 块 6000 步这个预算下的 null」，
  不得写成「域适配无效」。
- **RETFound 不是独立预训练**：patch_embed 与本项目用的 DINOv2-L cosine 0.955
  （打乱对照 −0.0017，所以血统确凿）。它与 dinov2l 容量、patch、几何全同，
  是最干净的预训练对照。
  **更正（7-E.3，实测于 `encoder_distance/retfound_vs_dinov2l.json`）**：本条原写
  「可能的差异幅度被这个相似度限住了」，这是错的。同一张量的相对 Frobenius 距离是
  0.495，深度剖面从 block0 的 0.463 掉到 block23 的 0.165 ——
  视网膜 SSL 实质重训了这个网络，一个输入层 cosine 对 24 个 block 之后的函数不构成上界。
  站得住的是血统：R0 对 A0L 是「续训语料」的对比，不是「医学 vs 通用预训练」的对比。
  许可证 CC BY-NC 4.0 → 只能做研究期对照，不能进产品。
- **MedSigLIP 不是纯预训练对照**：没有 CLS token，位置嵌入固定 1024=32×32，
  无法在部署的 518×686 上跑，也无法在 224 上适配。它的任何差异同时混入了
  分辨率、几何、池化定义（"cls" 槽装的是 attention-pooled 输出，是另一个东西）。
  HAI-DEF 条款把托管推理算作 Distribution、把监管许可作为再分发条件、
  允许单方终止，部署许可必须单独记录。
- 适配在 224/448 上做，读出仍用各臂自己的部署几何，**适配与读出分辨率不同**。
- 适配只用外部图像，读了 0 张本地图、0 个本地标签、0 个折，
  所以一个 checkpoint 对所有外层折都合法，不存在验证病例影响它的路径。

## 8 局部形态阶梯（A2 / A2x / A3）的预注册部分与事后部分

**预注册（在任何字段结果之前写死在代码里）**

- 字段列表：`FIELDS = ["malformation_ratio", "crossing_ratio", "papilla", "capillary_count"]`。
  四个字段来自拯救计划 §五第一优先级，不是看到结果后挑的。
- 臂：A2（本地人工框检测器）、A2x（外部预训练检测器）、A3（外部→本地微调），
  外加 `L2_*` 只用局部列的对照臂。
- 检测器超参：yolo11s、imgsz 640、40 epoch、seed 20260917，三套完全相同。
- 特征提取 conf = 0.25，**在看到任何字段结果之前定死，不逐字段调**。
- 判定阈值沿用本文件 §1：BA 配对差 ≥0.05 且 CI 排除 0 = `meets_effect_threshold`，
  0.02–0.05 = `below_resolution`，<0.02 = `no_effect`。
- 主要指标仍是 accuracy − 单一众数答案 = delta；BA 同时报告，不替换 delta。
- §六 的 LOAO、校准、拒答覆盖率在**每个字段的每个臂**上都算，

- 计数/比例的 NaN 语义：零检出 ⇒ 计数 0，比例保持 NaN（填 0 等于断言「畸形 0%」），
  由评估器在标准化后零填充；不用中位数，因为逐折重拟合会泄漏。
- 泄漏控制：看过本地图的 manifest 逐折训练；一个 original_id 的 20 张增强图整组同侧；
  验证病例不提供图或框，只接受自动检出区域。

**事后新增（必须标为预注册之后加的对照，不能算作预注册证据）**

- **打乱列对照** `scripts/control_shuffled_local_columns.py`。
  加它的原因是 `L2_*` 回答的是「这些列自己能不能预测」，
  **不能**回答「多加 54/64 列本身是否改变了 768 列问题的正则化几何」。
  设计：置换局部表行与病例的对应关系（声明种子 `SEED + s`，20 次），
  列数、边际分布、量纲、NaN 模式全部保留，只摧毁病例对应，整条 OOF 重跑。
  它**不改变任何判定阈值**，只给已有的 BA 差加一个参照分布。
  由于它是事后加的，它可以推翻一个增益（把它归给几何），
  但**不能被用来为一个不过阈值的增益加分**。
- `pca_survival()` 诊断同样是事后加的，用途相同：只能否证，不能加分。
