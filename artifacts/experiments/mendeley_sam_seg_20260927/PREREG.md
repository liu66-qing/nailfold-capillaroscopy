# Mendeley 红点 → SAM2 伪掩码 → 重训分割器；ANFC 三模型管线复现

写于运行前（2026-09-27）。结果只进 v3，不改 rag_heads_v2 冻结包与前瞻评估。

## 问题

1. 用 Mendeley SSc 红点作 SAM2 提示补进异常血管掩码后，分割器对畸形血管的系统性漏检（frac_low_circ vs malformation rho = −0.257）会不会翻正？
2. 按 ANFC 论文的专家管线（U-Net 分割 + ResNet18 正常/异常分类，关键点阶段见下）在我们字段上复现，是否优于 A0（rag_heads_v2 的 DINOv2 线性头）？即"是不是我们方法搞错了"。

## 数据与臂

- 分割训练共同底座：血管数据集 train_ready 分割 2332 张单血管裁剪（单类 vessel）+ ANFC-coco train 257 张（6 类合并为 vessel）。
- S0 对照：只用底座。
- S1 inpaint：底座 + Mendeley 单血管裁剪（红/黄叠加像素 cv2.inpaint 修复后的图）。
- S1n 不修复：底座 + 同一批 Mendeley 裁剪，但训练图保留叠加像素（SAM 提示一律在修复图上做）。
- 三臂同 seed、同超参、同 epoch、同验证集。验证集 = 血管数据集按文件号固定 10% + ANFC-coco valid（ANFC valid 的 42 个被试全部出现在 train，这一点照实报告，不当独立测试）。
- 本地没有 seg_vessel_v2 五折权重（服务器不可达），所以 −0.257 是历史参照；判定用本地 S0 重算的 rho。

## 尺度归一化（未解问题的处理方式）

Mendeley 无标定。用"相邻血管间距"作参照：Mendeley 红点簇质心最近邻中位 71 px（原图），我们 SAM 提议最近邻中位 81.9 px（1024 宽）。Mendeley 图按 81.9/71 放大后再切裁剪。SSc 血管密度降低会让这个比例偏小，是已知偏差，照实报告。

## 伪掩码规则（运行前固定）

- 30 px 单链聚类红点；每簇全部点作 SAM2.1-b 正提示。
- 保留条件：掩码覆盖该簇 ≥50% 的点；面积在底座多边形面积 p2~p98 之间（按尺度换算）；bbox 不超过图的 15%。
- 同一像素被两个掩码覆盖时，保留面积小的。
- 输出为单血管裁剪：bbox 四周各留 10% 边距，与血管数据集裁剪格式一致。
- 红点是 SSc 队列里被计数的毛细血管，不是"异常血管"专属标注；异常比例高是队列属性，不是标注属性。

### 修订 1（3 张图试跑后、全量运行前）

- 整图点提示失败：10 张图 70 簇的掩码对比度（环带灰度均值 − 掩码内灰度均值，除以环带 std）中位 −0.42，与随机点（−0.40）无差别。SAM 在整图上分出的是背景大块（面积 2.6 万~14 万 px）。
- 改为：以簇质心为中心切 160×160 原图块，放大 4 倍后做点提示。同样 70 簇：对比度中位 0.69，53% 超过人工多边形 p10（0.66）；随机点 13%。
- 新增保留条件：对比度 ≥ 0.66（人工多边形对比度的 p10，取自血管数据集 300 个多边形，不看任何临床标签）。
- G1 目视检查无法执行（本环境读图不返回内容），改由上面的对比度分布 + 随机点对照代替，照实报告。
- 红点处比随机内容区暗（AUC 0.694，中位暗度 18.0 vs 5.3），点正上方 10 px 仍暗 17.0，说明红点落在血管上，这支持用它作提示。

### 修订 2（5 张图试跑后、全量运行前）

- 局部点提示保留的掩码中位 32×32 px；人工多边形外接框中位 34×111 px（w p25~p75 27~42，h 85~143）。SAM 只分出红点处的暗斑（环顶附近），不是整条血管环。框提示（向下延伸或居中）对比度中位 −0.03/−0.14，漏进背景。
- 直接把这些掩码当训练目标会教分割器"血管是小斑点"，与底座标注对象不一致，所以不采用。
- 改为"红点验证 + 分割器提议"：
  1. 先训 S0（仅底座）。
  2. S0 在 Mendeley 修复图（按 SCALE 放大）上推理，conf 0.05。
  3. 红点召回 = 被任一 S0 实例覆盖的红点簇占比。这本身就是"分割器漏检 SSc 血管"的独立度量（不依赖我们的临床标签）。
  4. 伪标签 = 覆盖红点簇的 S0 实例（人工红点验证过的检出）∪ 未被覆盖的红点簇的 SAM 局部掩码（仅在对比度 ≥ 0.66 时，标记为 sam_fill）。
  5. 训练图 = 以红点簇为中心切 640×640 窗口；窗口内 S0 conf ≥ 0.25 的其他实例也保留为正样本，避免把已检出血管教成背景。
- 新增报告项：S0 在 Mendeley 上的红点簇召回。召回已很高（≥ 0.9）则说明 SSc 血管并未被系统性漏检，G3 预期不会翻号。
- 底座单血管裁剪按原生尺度平铺到 640×640 画布（不放大），与全视野推理尺度一致。原 seg_vessel_v2 在裁剪上的 mAP 0.952 不可与本实验的画布 mAP 直接比较。

### 修订 3（伪标签脚本写完、S0 训完前；只用 2 张图和第 7 轮权重做冒烟测试，不看任何数字做选择）

- 实际底座画布是 1024×1024（不是修订 2 写的 640），训练 imgsz 1024。为保持同一像素尺度，Mendeley 放大图（1949×1093）切成 1024×1024 的角点平铺块（每图 4 块，允许重叠），不再按红点簇切 640 窗口。块内全部伪标签实例都写入，所以窗口内非红点区域的 S0 高置信实例仍作正样本，原则与修订 2 相同。
- S0 推理在放大图上用 imgsz 2048（等于原生尺度），与我们 233 例 imgsz 1024（原图约 1024 宽）的像素尺度一致。
- 伪标签成分计数（红点验证实例 / conf ≥ 0.25 实例 / sam_fill / 对比度拒绝）全部写入 summary.json。

### 修订 4（S0 训练中、伪标签尚未生成；纯算力原因）

- 4 块全用时 S1 训练集 = 292 底座 + 2288 块，约为 S0 的 9 倍，按实测 2 min/epoch 推算每臂约 12 h。改为每张 Mendeley 图按固定种子 20260927 只取 1 块（572 块），S1 与 S1n 取同一批块位置。每臂约 4~5 h。
- 这只改变额外数据量，不改伪标签规则、验证集和门槛。

## 判定门槛（运行前固定）

G1 伪掩码质量：随机抽 40 个叠加图人工目视，我只报告我看到的，不拿来调参。
G2 分割任务：S1 在共同验证集上的 mask mAP50 不低于 S0 超过 0.02（不损坏原任务）。
G3 翻号检验（主判定）：在 233 例上，S1 的 frac_low_circ vs malformation Spearman rho > 0 且 S0 ≤ 0；或 S1−S0 的 rho 差的 bootstrap 95% CI 下界 > 0。两者都不满足 = 否证。
G4 下游：LOAO 三档案、A0 五池化 + 几何特征块作第六路，配对 bootstrap BA(A0+geom_S1) − BA(A0) 的 CI 下界 > 0，字段只看 malformation_ratio 与 crossing_ratio。
G5 ANFC 复现：U-Net 在共同验证集上的像素 SE/F1 与论文（SE 0.653, F1 0.487）同量级即视为复现成功；ResNet18 正常/异常分类器下传得到的病例级异常占比，同 LOAO 尺子下 vs A0 比较。
关键点阶段：本地三个外部数据集没有关键点，官方关键点需签协议且禁商用。不伪造关键点训练；管径字段的比较在报告里标为"无法复现"。
