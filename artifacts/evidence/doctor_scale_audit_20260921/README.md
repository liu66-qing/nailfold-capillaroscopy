# 医生评分尺度是否被混进字段任务里 —— 实测

复现：`PYTHONIOENCODING=utf-8 python scripts/audit_doctor_scale_conflation.py`

`artifacts/evidence/allfields_20260919/all_fields_status.{csv,json}`。哈希见 `verdict.json`。

## 先回答问题本身

**不是在做逐结构分割分类。** 交付配置（`scripts/evidence_all_fields_status.py`）是
冻结 DINOv2 ViT-B/14 整图特征 → 5 种空间池化 → PCA(64) → 逻辑回归，每个字段一个
二分类头。它没有定位任何一根血管、任何一个乳头。它拟合的就是**医生阈值化之后的那一格离散
报告值**。你的判断在这一点上是对的，而且比"混在一起"更严重：其中 15 个字段被压成了二分类，
连医生的档位数都没保留。

**但"拟合医生评分习惯"也不准确。** 有两件事是分开的，实测支持：医生的**打分规则**稳定，
医生的**读数**不稳定。见下面 P3/P4。

## P1 标签文件里没有逐字段积分列

## P2 那一列其实印在报告图上，只是从没 OCR

## P3 组分小计是否是字段值的加法函数（one-hot 最小二乘上界）

| 组 | n | mean\|err\| | R² | 可加 |
|---|---|---|---|---|
| morphology_score | 142 | 0.1755 | 0.9515 | 是 |
| flow_score | 173 | 0.0898 | **0.9963** | 是 |
| periloop_score | 152 | 0.6445 | **0.5851** | **否** |

one-hot 最小二乘是**任何**加法规则表的上界。flow 组几乎完全可加，说明医生在这一组严格按表打分。
periloop 组 R²=0.5851 不是 OCR 噪声：限定 conf≥0.99 仍是 0.6422/R² 0.5773，残差连续分布，
且三个组分之和等于总分的比例是 99.4%——不一致发生在组内部。

## P4 是边界漂移还是读数漂移

逐档案检查 exudation / clarity / papilla / blood_color / SVP 的每个取值对应积分：
**5/5 字段 boundary_stable=True**。同一个词在三个档案里得同一个分。
漂移的是**标签分布**：archive3 loop_length 中位数 297.5 对 236/234，archive3 不清占 0.520，
archive2 浅波纹状占 0.494。

所以你第 4 条主张里"同一医生随整体病情移动边界"这一半**没有得到支持**——打分表没动。
被支持的那一半是：不同档案的读数口径不同，这与已实测的 SVP/blood_color 档案依赖一致。

## P9 精度问题的直接回答

| 字段 | 我们的 MAE | 落在某阈值 ±MAE 内的比例 | 按此 MAE 扰动后积分误差 | 仍在原档的比例 |
|---|---|---|---|---|
| afferent_diameter | 8.47 | **0.976** | 0.6994 | 0.158 |
| efferent_diameter | 4.27 | 0.963 | 0.1646 | 0.354 |
| apex_diameter | 7.19 | 0.893 | 0.2689 | 0.284 |
| loop_length | 66.40 | 0.920 | 0.3762 | 0.358 |

89–98% 的病例离某个医生阈值的距离小于我们自己的测量误差。按当前 MAE 随机扰动，
afferent 只有 15.8% 留在原档，积分平均错 0.6994 分——比 clarity 全字段押的 0.1535 分还多。

**这就是你问的"医生尺度是否影响精度"的答案：影响方向和你想的相反。**
不是医生的阈值让模型学不准；是我们的测量分辨率粗于医生的阈值间距，所以无论标签怎么重编码，
档位归属都由小于我们分辨率的差异决定。重编码换靶子，不给分辨率。

## 结论

1. 你说我把四件事混在一套任务里，成立。而且是用二分类压平的，连档位都没留。
2. 医生的**打分表**稳定（5/5 边界一致、flow 组 R² 0.9963）；不稳定的是**读数**和 periloop 组。
   所以"医生尺度"不是主因。
3. 主因仍是已封闭的那条：单位（需时间基/需整视野）+ 分辨率（P9）。
4. 你自己划的边界是对的：重编码给不了静态图时间信息，也给不了裁剪图整视野。
   它还给不了分辨率——这一条你没提到，但 P9 说明它更致命。
