# 甲襞微循环自动分析项目阶段汇报

## 一、项目目标

从甲襞微循环检查病例文件夹（含图片、视频、病例报告）出发，构建端到端自动分析系统，自动预测17个临床指标。评价标准：在47例独立锁定测试集上的平均 balanced accuracy ≥75%。

## 二、数据资源

| 数据 | 规模 | 用途 |
|------|------|------|
| CAPorg病例 | 241例（185例有效开发 + 47例锁定测试 + 9例排除） | 主训练与评估 |
| ANFC-THU分割数据 | 257张图，5363个实例标注（6类） | 分割模型训练 |
| OCR提取标签 | 241行病例级数值 | 弱监督信号 |

关键数据事实：
- 每个病例文件夹内图片是从该病例视频中随机截取的若干帧
- 报告中的数值是这些帧测量值的平均
- 无帧级、实例级医生标注，仅有病例级OCR提取的报告数值

## 三、技术方案

### 3.1 整体架构

```
原始图片/视频 → YOLOv11-seg分割 → 几何测量 + 特征提取 → 分类/回归 → 17个指标预测
```

### 3.2 分割模块

- 模型：YOLOv11l-seg，输入1024×1024
- 训练数据：ANFC-THU 257张，6类（normal, abnormal, aggregation, blur, hemo, capillary）
- 验证结果：mask mAP50 = 0.424
- 作用：提供管袢实例mask，支撑下游所有计算

### 3.3 几何测量模块（确定性算法）

对每个normal/abnormal类管袢mask：
- 距离变换 → 提取中轴线宽度（输入支直径、输出支直径、袢顶直径）
- 骨架化 → 测量管袢长度
- 按archive分层标定像素-微米因子（不同设备/倍率需独立校准）

### 3.4 分类模块

- 特征：DINOv2-ViT-B(768d) + 分割统计特征(16d)
- 模型：GBT / SVM / ordinal回归，内层CV自动选择
- 帧级预测 → 病例级概率均值聚合
- 管袢数：专用计数路由（多阈值检测 + 骨架展开 + GBT校准器）

### 3.5 验证体系

- 严格嵌套5-fold CV：外层评估、内层选模型，同病例所有帧绑定在同一fold
- 47例锁定测试集全程未参与任何训练、特征选择或阈值调整
- 单次评估，评估后冻结，不回看调参

## 五、已尝试但未能突破的方法

| 方法 | 预期 | 实际 | 结论 |
|------|------|------|------|
| 高置信伪标签自训练 | 提升分割→提升计数 | 计数从0.363降到0.262 | 伪标签噪声抑制了关键类 |
| DINOv2多任务微调 | 端到端学习分类 | 提升不显著 | 185例过拟合 |
| Hulu-Med-7B特征 | 医学预训练优势 | 与DINOv2互补有限 | 数据量是瓶颈非特征 |
| Ordinal回归 | 利用等级顺序 | 部分字段+1-3点 | 收益有限 |
| 帧级MIL | 利用多帧信息 | 部分字段+5-10点 | 已纳入最终模型 |
| Classifier chain | 利用字段间关联 | 无显著提升 | 标签噪声传播 |

## 六、核心困难与瓶颈分析

### 6.1 根本瓶颈：标注缺失

9个分类字段只有病例级OCR值（从报告提取），没有：
- 帧级标注（哪一帧显示了渗出）
- 实例级标注（哪个管袢是畸形的）
- 分级标准说明（等级1和等级2的视觉差异是什么）

这导致模型只能做"从整张图的统计特征猜一个等级"，而非"看到具体证据做判断"。

### 6.2 数据量限制

- 有效开发病例仅185例
- 部分字段类别极度不平衡（如渗出=0占80%+）
- 深度模型（微调DINOv2）在此规模上无法收敛

### 6.3 主观性问题

渗出、静脉丛可见度、乳头形态等字段本身就是医生主观判断，没有客观可测的物理量对应，纯视觉特征无法可靠推断。

## 七、下一步计划

### 7.1 可自力解决（不需要医生）

| 字段 | 方案 | 预期提升 |
|------|------|------|
| 管袢数 | 人工数20-30张图 → 拟合校准回归 | →60%+ |
| 畸形比例 | 修正abnormal/(normal+abnormal)计算+阈值对齐 | →55%+ |
| 血色 | 提取LAB/HSV色彩统计特征 | →55%+ |
| 清晰度 | Laplacian方差等图像质量指标规则判定 | →60%+ |
| 出血 | hemo分割面积→等级映射表（对照10-20例报告） | →60%+ |
| 交叉比例 | 骨架交叉点检测+阈值校准 | →65%+ |

### 7.2 必须补充医生标注

| 字段 | 需要 | 工作量 |
|------|------|------|
| 渗出 | 50-100例分级标注 | 医生1-2小时 |

## 八、硬件与工程

- 训练设备：2×RTX 5090D 32GB
- GPU:0 — YOLO训练/推理、DINOv2特征提取
- GPU:1 — Hulu-Med-7B特征提取（~14GB bf16）
- 全流程自动化：Codex目标模式自主执行14个步骤，含gate验收和失败自动修复
- 总计算耗时：约12小时GPU时间

## 九、关键设计决策与依据

| 决策 | 原因 |
|------|------|
| 不用VLM做主模型 | 2卡5090D跑不了70B级VLM推理+训练 |
| YOLOv11而非SAM2 | 实例分割需要类别信息，SAM无类别 |
| 骨架法测量而非深度回归 | 确定性可解释，无需额外标注 |
| 47例锁定不回看 | 产品级验证标准，避免信息泄漏 |
| 分层像素校准 | 三个archive设备倍率不同 |
| GBT而非神经网络分类 | 185例不足以训练深层模型 |
