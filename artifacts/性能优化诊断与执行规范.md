# 性能优化诊断与版本化执行规范

## 目标
在不污染既有 locked 评估的前提下，判断性能瓶颈来自等级粒度、标签噪声、实例分割/计数，还是病例帧监督方式；再选择最小改动方案。当前 v1 locked 结果（47例、0.6902）只作为基线，禁止重新用于调参。

## 冻结边界
- 冻结 v1 基线：Step 12 路由、分类器、阈值、特征定义、病例隔离划分、几何算法和标定参数。
- 强保护字段：输入支直径、输出支直径、袢顶直径、袢长。任何新版本必须报告四项 MAE/归一化分数，不能退化超过预先设定容差。
- 允许在新分支 v2 迭代：弱字段分类头、标签权重、MIL 聚合、计数后处理、分割模型。改动分割后必须全字段重跑开发集。
- 原 locked 集不得参与 v2 的任何选择；v2 完成后建立新的 locked 集。

## 阶段一：纯计算诊断
1. 等级合并：6个弱字段分别比较原始等级、3级、2级；输出 BA、每类召回、混淆矩阵、有效样本数。不得直接替换产品定义。
2. 高置信子集：按 OCR 两路一致/不一致/缺失分组，计算各字段开发集 OOF BA；注明这是 OCR 一致性代理，不是医生 kappa。若一致子集明显更高，再测试样本加权，不盲删样本。
3. 管袢数归因：逐病例输出 mask 数、面积、连通域、skeleton 分支、比值、阈值计数、帧间方差、archive/设备/质量；用规则标记漏检、粘连、阈值偏移候选，并给出分布与混淆矩阵。
4. 诊断报告必须包含“已证据支持/尚不能判断”，不写未经验证的提升承诺。

## 阶段二：选择性低成本实验
- 合并等级有效：在开发集定义新的交付粒度，重训对应 GBT；同时保留原始粒度基线。
- 标签噪声明显：一致样本提高权重、不一致样本降权/剔除做对照，报告样本量变化。
- 粘连主导：先 watershed/距离变换或 concavity splitting；比较计数误差及强保护几何字段。
- 漏检主导：阈值扫描+质量分层+FP规则过滤；只有证据支持时才降低置信度阈值。
- 帧间差异明显：实现病例 bag-level MIL/ABMIL；禁止把简单帧后聚合称为 MIL。

## 阶段三：分割 v2
只有阶段二证明分割是主因才执行：外部血管预训练（若数据/标签适配成立）→ 甲襞 finetune → 新开发集全字段验证 → 强保护字段非退化检查 → 新 locked 集一次性评估。

## 判定门槛
- 诊断不以“平均分提高”作为唯一依据；必须有字段级、类别级和错误机制证据。
- 新实验必须保留 v1 对照、固定病例划分、记录随机种子和样本数。
- 强保护几何字段任何显著退化即停止该分支。
- RAG 健康专家模型属于输出解释层，不计入识别性能提升；必须引用知识来源、显示不确定性、提示医生复核，不作诊断替代。
