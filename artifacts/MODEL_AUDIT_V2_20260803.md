# 最终模型审计 v2（2026-08-03）

## 结论

工程交付完整，效果门禁 No-Go。

最终模型能够在 Windows 本地读取病例多图和 AVI/UVC 视频，输出 20 个医生报告
字段、字段置信状态、证据图片、三个分项积分、总积分和综合判断。报告字段之间的
比值与积分关系是确定性的，不会再相互矛盾。

47 例算法锁定集没有证明医生级准确率，部分分类字段明显不足，因此不得用于临床
诊断、筛查或替代医生。

## 最终组件

- `windows_model_hybrid`：SigLIP2 Base NaFlex，共享 attention MIL＋15 个字段
  独立 attention/top-k MIL；病例最多 8 张图。
- `geometry_final`：在原始 1024×768 图上训练的颜色、血管增强、连通域、骨架
  候选和距离变换特征。
- `video_hybrid_final`：最终视觉编码器的 32 帧特征、帧差、Farneback 光流及
  Logistic/ExtraTrees 集成。
- `score_rules.json`：从报告积分列重建的确定性字段积分规则。
- `multisource_confidence_v1.csv`：JPG 多副本、RapidOCR、Qwen OCR、RTF 弱语义
  和逻辑约束形成的字段级置信标签。
