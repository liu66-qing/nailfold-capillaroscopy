# 甲襞微循环智能分析系统 — 项目资料

## 项目背景与应用场景

甲襞微循环检查是评估人体末梢微循环状态的无创检测手段，通过观察手指甲襞处毛细血管的形态、血流和周围组织变化，辅助判断微循环障碍相关疾病（雷诺现象、糖尿病微血管病变、结缔组织病早期筛查等）。

当前临床流程的痛点：

| 痛点 | 具体表现 |
|------|----------|
| 效率低 | 一份完整报告需要医生逐项测量和判读，耗时15-30分钟/例 |
| 主观性强 | 分级字段（渗出、血色等）依赖个人经验，不同医生判读结果存在差异 |
| 人才稀缺 | 具备甲襞判读能力的医生数量有限，基层医疗机构难以开展 |
| 标准化难 | 缺乏统一的量化标准，不利于纵向随访对比 |

系统的应用价值：将专家级判读能力封装为软件服务，使基层机构和健康管理场景也能获得标准化的甲襞微循环分析报告。

## 项目目标

项目要解决的核心问题是：当前甲襞微循环检查依赖医生人工读片，从一组图片和视频中逐项判断管袢形态、测量管径袢长、评估血色渗出等20个字段，再根据各项数值进行综合解读。这个过程耗时、主观性强，且依赖有经验的医生。

我们的目标是构建一套端到端的智能分析系统，分为两个核心能力层：

1. **视觉分析层**：输入病例检查材料（图片、视频），通过分割、几何测量和分类模型，自动输出17个结构化临床指标（管袢数量与形态、管径袢长、血色渗出出血等分级）。

2. **健康专家层**：基于RAG（检索增强生成）架构，接入甲襞微循环专业知识库，对视觉分析层输出的结构化数值进行综合解读，生成专家级健康建议和个性化报告。

系统部署形态为Windows本地推理，支持导入病例文件或连接UVC采集设备。后续封装HTTP接口对接甲方现有平台。

## 技术方案

### 多路线架构设计依据

甲襞微循环的17个临床字段可归纳为三类异构任务，其数据特征、误差来源和最优求解策略存在本质差异：

| 任务类型 | 代表字段 | 数据特征 | 核心挑战 |
|----------|----------|----------|----------|
| 连续几何测量 | 管径、袢顶直径、袢长 | 有明确物理定义，可从像素级mask精确计算 | 标定精度、测量位置一致性 |
| 有序分级判断 | 血色、渗出、出血、清晰度等 | 病例级主观评估，无单一可测物理量对应 | 标注稀缺、类别不平衡、帧间变异 |
| 实例计数 | 管袢数 | 依赖检出完整性与实例去重 | 密集粘连、置信度阈值敏感 |

单一端到端模型无法同时满足三类任务对精度、可解释性和鲁棒性的不同要求。因此采用**统一分割前端 + 任务专用路线 + 病例级融合**的分治架构，各路线独立优化后在病例级形成闭环。

### 视觉分析层

#### 统一前端：实例分割

| 项目 | 规格 |
|------|------|
| 模型 | YOLOv11l-seg |
| 输入分辨率 | 1024×1024 |
| 输出 | 逐实例类别标签 + 像素级mask + 置信度 |
| 类别体系 | normal / abnormal / aggregation / hemo / blur / capillary |

选型依据：下游路线均需要实例级类别信息（如畸形比例 = abnormal / (normal + abnormal)、出血面积 = hemo mask面积），SAM系列模型仅输出类别无关mask，无法支撑后续计算。

#### 路线A：确定性几何测量

适用字段：输入支直径、输出支直径、袢顶直径、管袢长度

| 处理阶段 | 算法 | 输出 |
|----------|------|------|
| 形态学中轴提取 | 二值mask → 距离变换 → 形态学骨架化 | 单像素宽中心线 |
| 解剖定位 | 骨架最高点为袢顶；沿骨架下行至60%-80%处定位输入支/输出支截面 | 测量锚点坐标 |
| 管径估计 | 锚点处距离变换值 × 2 | 管径（pixel） |
| 物理标定 | 按数据来源（archive）分层的像素-微米转换因子 | 管径（μm）、袢长（μm） |

设计原则：全链路确定性计算，无可学习参数，结果可精确复现与人工审计。在当前数据条件下已达到 MAE 3.09-5.08 μm（得分83-99%）。

#### 路线B：视觉语义分类

适用字段：清晰度、血色、交叉比例、畸形比例、渗出、出血、乳头下静脉丛、乳头形态、血管运动

| 处理阶段 | 方法 | 维度/说明 |
|----------|------|-----------|
| 全局视觉编码 | DINOv2-ViT-B（冻结权重） | 768d CLS token |
| 结构化统计特征 | 分割结果衍生：各类实例数、面积比、形态统计 | 16d |
| 特征拼接 | concat(视觉编码, 结构化统计) | 784d |
| 分类器训练 | GBT / Linear SVM / RBF SVM，嵌套CV内层自动选优 | 逐字段独立模型 |
| 病例级聚合 | 帧级后验概率 → 病例级均值池化 → argmax | 多帧投票降噪 |

选型依据：有效开发病例仅185例。实验验证DINOv2端到端微调在此规模下严重过拟合（验证集loss持续上升）；冻结特征 + 浅层分类器泛化更稳定，且训练成本可忽略（CPU数秒）。

#### 路线C：管袢计数

适用字段：管袢数

| 处理阶段 | 方法 | 解决的问题 |
|----------|------|------------|
| 有效实例筛选 | 仅保留 normal + abnormal 类检出 | 排除blur/hemo等非管袢结构 |
| 密集实例拆分 | 大面积mask骨架分支计数 | 聚集区单个检出框含多根管袢 |
| 阈值鲁棒性 | 多confidence阈值下计数取稳定值 | 消除单阈值敏感性 |
| 病例级校准 | GBT回归器（检出特征 → 报告管袢数） | 系统性偏差修正 |

设计依据：直接将检出实例数等同于管袢数会引入严重误差——密集粘连区一个bbox含3-5根管袢、低置信漏检、blur类误计入。专用计数路线通过拆分和校准消除这些系统偏差。

#### 病例级融合闭环

```
路线A/B/C 各自帧级输出
    → 按病例ID分组
    → 聚合策略（几何取中位数、分类取均值概率、计数取校准值）
    → 合并为17字段结构化JSON
    → 规则引擎计算积分与综合判断
    → 输出结构化报告
```

### 健康专家层

视觉分析层输出结构化数值，健康专家层负责将数值转化为临床可理解的解读与建议。采用RAG（Retrieval-Augmented Generation）架构，确保生成内容有据可查。

#### 架构设计

| 组件 | 实现方案 | 职责 |
|------|----------|------|
| 领域知识库 | 甲襞微循环教材、临床诊断指南、积分评价标准、疾病关联文献 → 分块 + embedding向量化 | 提供可检索的专业知识底座 |
| 异常识别模块 | 17字段数值与正常参考范围比对，输出偏离方向和程度 | 确定需要重点解读的指标 |
| 语义检索引擎 | 基于异常指标组合构造query，向量相似度召回Top-K知识片段 | 精准匹配相关医学知识 |
| 生成模型 | 大语言模型接收"结构化数值 + 检索知识片段"作为context | 综合推理，生成自然语言报告 |

#### RAG架构的技术优势

| 对比维度 | 直接生成（无RAG） | RAG检索增强 |
|----------|------------------|-------------|
| 知识覆盖 | 依赖模型预训练语料，甲襞细分领域覆盖不足 | 知识库精确覆盖甲襞微循环全部诊断标准 |
| 可溯源性 | 无法追溯生成依据 | 每条建议关联具体知识来源，可审计 |
| 可维护性 | 更新知识需重新训练 | 新增指南/文献入库即生效，零训练成本 |
| 幻觉控制 | 易生成无根据内容 | 受限于检索结果，幻觉风险显著降低 |

#### 输出规格

| 面向对象 | 输出内容 | 表述风格 |
|----------|----------|----------|
| 临床医生 | 异常指标解读 + 可能关联病种 + 建议补充检查项目 | 专业术语，直接呈现证据 |
| 健康用户 | 通俗健康提示 + 生活方式建议 + 复查时间建议 | 易理解，避免恐慌性表述 |

## 健康专家层设计

**【此处插入专家层示意图或示例报告截图】**

系统在视觉分析完成后，将17字段结构化结果送入健康专家模块：

**工作流程：**

1. **异常检测**：识别哪些指标偏离正常范围（如管袢数偏少、输出支增粗、渗出评分偏高）
2. **知识检索**：根据异常指标组合，从知识库中召回相关临床解释和健康指导
3. **综合生成**：大语言模型结合数值结果和检索知识，生成结构化健康建议

**输出示例：**

> **指标解读**：输出支直径/输入支直径比值偏高（1.8），提示静脉回流阻力增大；管袢形态中畸形比例30%，高于正常范围。
>
> **健康提示**：上述表现常见于微循环障碍早期，建议关注末梢循环状况。
>
> **建议**：定期复查，注意保暖和适度运动，避免长时间保持同一姿势。如有手指发凉、麻木等症状加重，建议就医。

**知识库内容范围：**
- 甲襞微循环形态学教材
- 各指标正常值范围与临床意义
- 微循环异常与常见疾病的关联（雷诺病、糖尿病微血管病变、结缔组织病等）
- 积分标准与分级解释
- 健康管理建议

## 效果差距与原因

目标75%，当前69%，差距来自9个分级字段（平均45.7%）。

| 原因 | 说明 |
|------|------|
| 缺乏医生分级标注 | 只有病例级OCR报告值，无帧级/实例级标注，无分级标准定义 |
| 数据量有限 | 有效开发病例185例，部分类别极度不平衡 |
| 主观字段本质 | 渗出、静脉丛等为医生综合判断，无单一可测物理量对应 |

## 已尝试的方案

| 方案 | 结果 |
|------|------|
| 伪标签自训练 | 性能反降（噪声传播） |
| DINOv2多任务微调 | 185例过拟合，无显著提升 |
| Hulu-Med-7B医学特征 | 与DINOv2互补有限 |
| Ordinal回归 | 部分字段+1-3点 |
| 帧级MIL聚合 | 部分字段+5-10点，已纳入 |
| 分类器链 | 标签噪声传播，无提升 |
| SAM2/MedSAM分割 | 缺少像素级真值和比例尺，暂只能生成候选mask |
| Qwen3-VL零样本/QLoRA | JSON格式稳定但分类向多数类坍缩 |
| SigLIP2视觉编码 | 仅乳头字段确认胜出，其余无稳定提升 |

| 维度 | 市面已有方案 | 本系统 |
