# 血管数据集人工审核教程

## 目的与原则

本教程用于审核 `data/血管数据集`，不直接修改原始图片、XML、YOLO、JSON 或 mask。审核结论写入独立的审核记录，之后再由脚本生成清理后的派生清单。

四条硬规则：

1. `locked_test` 病例及其增强派生物永久排除，不能用于训练、调参、阈值选择或模型选择。
2. 增强图继承原图的病例归属，只能跟随原图进入同一 split，不能当作独立样本。
3. 同学标注是候选监督，不自动视为临床金标准；必须先确认来源、语义和配对。
4. 任何无法确认的样本标记为 `HOLD`，不要为了提高可用数量而猜测。

## 使用文件

先打开以下文件：

- `manual_review_queue.csv`：按优先级汇总的审核任务。
- `governance_manifest.csv`：逐文件状态、原图编号、增强编号和 locked/development 关系。
- `governance_report.md`：本次自动审计的事实和数量。
- `governance_summary.json`：机器可读汇总，供复核数量。

审核结果另存为：

`artifacts/audits/vascular_dataset_governance_20260829/manual_review_decisions.csv`

不要在 `data/血管数据集` 原目录内覆盖文件。

## 推荐审核顺序

### 第 0 步：建立审核记录

每条审核记录至少包含以下字段：

```text
review_id,asset_path,case_id,source_layer,issue_category,
reviewer,review_time,decision,reason,corrected_value,evidence_path
```

`decision` 只使用以下值：

- `PASS`：证据充分，可进入下一阶段。
- `PASS_AUXILIARY`：只能作为辅助监督，不能当金标准。
- `HOLD`：信息不足，暂不训练。
- `EXCLUDE_LOCKED`：与 locked 病例重叠，永久排除。
- `EXCLUDE_DUPLICATE`：重复副本，保留 canonical 文件。
- `REPAIR_REQUIRED`：需要在派生目录修复后重新审核。
- `REJECT`：标注或来源不可接受，隔离。

每条 `PASS` 或 `REPAIR_REQUIRED` 都要填写理由和证据文件；禁止只填“看过了”。

### 第 1 步：先锁定排除集（P0）

在任何图像质量审核前，筛出 `locked_overlap=yes` 的全部文件：

- 17 个 locked 病例；
- 32 个本地分类原图；
- 640 个增强派生物。

逐病例确认原图和所有 `<original_id>_<augmentation_id>.jpg` 均被标记为 `EXCLUDE_LOCKED`。不要打开这些图像来挑选“看起来有用”的样本，也不要把它们用于抽样阈值制定。

### 第 2 步：确认来源与病例映射（P0）

对 449 张未能直接映射到 recovered 病例的分类原图，人工核对：

1. 原始病例编号或受试者编号；
2. 采集设备、倍率、日期和操作者（如果有）；
3. 是否与现有 development 或 locked 病例重复；
4. 使用权限和数据来源证明；
5. 是否属于同一病例的多帧或增强图。

可接受证据包括原始导出清单、采集记录、原始压缩包路径或内容哈希。只有文件名相似不能作为病例映射证据。无法证明来源的样本保持 `HOLD` 或 `REJECT`。

### 第 3 步：统一标签语义（P0）

在看模型结果前，先写一页操作性定义，并由负责标注的人确认。至少要回答：

- `cross_vessel`：交叉是否要求两条血管真实相交，还是投影重叠也算；
- `malformed_vessel`：弯曲、扩张、分叉、断裂分别如何处理；
- 出血：判定可见出血的最小证据和排除条件；
- 乳头下静脉丛（SVP）：不可见、1 排、2 排、扩张的边界；
- 乳头：异常、正常、不可见的边界；
- 汗腺导管：可见与不可见的观察窗口和模糊图处理。

对每个字段准备 3 类示例：明确阳性、明确阴性、边界/不可判定。边界样本应允许 `HOLD`，不能强行二分类。

### 第 4 步：审核 XML/YOLO 标注（P0/P1）

#### XML 异常框（9 个）和 YOLO 异常行（7 行）

逐条打开原图和标注叠加图，检查：

- 框是否在图像范围内；
- 左上角是否小于右下角；
- 框是否覆盖真实血管而非背景、碎片或文字；
- 类别是否符合已批准的定义；
- 是否漏标明显目标。

判定规则：

- 目标真实、坐标可修复：`REPAIR_REQUIRED`，把修复值记在 `corrected_value`，不要覆盖原 XML/YOLO；
- 目标不存在或类别无法判断：`REJECT`；
- 需要临床定义才能决定：`HOLD`。

#### XML 尺寸不一致（485 个）

同时显示 XML 声明尺寸和实际图片尺寸。只有在确认图片是同一原图的缩放版本、且所有坐标可按同一比例变换时，才能提出坐标重标定；否则 `HOLD`。严禁只按宽高比例自动缩放后直接放行。

#### XML filename 无法配对（46 个）

使用原图内容、哈希、导出清单或人工视觉比对重建映射。仅凭数字文件名推断配对不合格。无法确认的 XML 隔离。

### 第 5 步：审核分割 JSON、图像和 mask（P0）

分割数据当前存在 JSON 路径不可解析、顺序漂移和尺寸不一致，不能按文件名直接配对。

每个待放行样本需要同时确认：

1. JSON 中的图像内容或可追溯来源与本地 JPG 相同；
2. mask 与该图像尺寸完全一致；
3. polygon 覆盖的是血管前景，而不是背景；
4. 遮挡、断裂和边界是否按定义处理；
5. 二值 mask 是否保留了所有应保留的血管区域。

重点人工处理 1,557 个尺寸/索引漂移样本和 109 个无 `imageData` JSON。确认后把正确的三元组写入派生配对表：`image_path,json_path,mask_path,pair_evidence`。

`_background_` 多边形和二值 mask 的含义必须抽查确认；不能只从类别名称推断前景语义。

### 第 6 步：抽样质量审核（P0）

至少抽查：

- 100 张分类原图：覆盖各标签类别、异常文件、不同图像尺寸和不同来源；
- 100 对分割图/mask：覆盖有/无 imageData、尺寸一致/漂移、不同 polygon 数量。

抽样记录：漏标数、错标数、不可判定数、配对错误数、图像质量问题和审核耗时。若两名审核者参与，计算一致率；对分歧样本保留双方意见和最终裁决，不删除分歧记录。

建议放行门槛：

- 关键字段或配对错误率 >5%：该子集继续 `HOLD`；
- 1%–5%：只能 `PASS_AUXILIARY`，先修复再训练；
- <1% 且无系统性错误：可申请 `PASS`，仍需保留抽样证据。

这些阈值是数据治理门槛，不是临床性能结论。

### 第 7 步：确认物理标定（P0）

在使用任何“长度、直径、密度、微米”指标前，必须确认：

- 设备型号和成像倍率；
- 像素到微米的转换关系；
- 是否存在裁剪、缩放或非等比例变换；
- 不同来源图像是否使用同一标定。

没有可靠标定时，几何结果只能报告为像素单位或相对量，不能写成微米级临床测量。

## 放行与回退

人工审核结束后，不修改原始文件。根据审核记录生成新的派生 manifest：

- 只含 `PASS` 的数据：可作为训练候选；
- `PASS_AUXILIARY`：只能作为辅助预训练/一致性检查；
- `HOLD`、`REPAIR_REQUIRED`、`REJECT`：不得进入训练；
- `EXCLUDE_LOCKED`、`EXCLUDE_DUPLICATE`：永久排除或仅保留 canonical。

任何新发现的病例重叠、标签定义冲突或配对错误，都触发回退：撤销该批次放行状态，回到对应审核步骤，不覆盖 v1 或既有评测结果。

## 人工审核完成的最低交付物

审核结束时应有：

1. `manual_review_decisions.csv`：逐项决定、理由和证据；
2. 批准的标签定义文档；
3. 修复后的派生 XML/YOLO 或 JSON-image-mask 配对表；
4. 抽样审核统计和分歧记录；
5. 新的候选训练 manifest；
6. 一份声明：locked 是否完整排除、增强是否按原图分组、物理标定是否可用。

在这些交付物完成前，本数据集的正确状态仍是 `HOLD`，而不是“可直接训练”。
