# 关键认知：从 0.71 到 0.90 不能只靠加特征

v3 证明新特征可以把 BA 从 0.66-0.69 提到 0.71。但从 0.71 到 0.90 还需要 +19pp，这大概率需要：
1. **更强的视觉表示**（不只是冻结 DINOv2 mean，要微调或用更好的 pooling）
2. **分割驱动的像素级特征**（2,332 对 mask 还没用，这是最大的未开发资源）
3. **任务专用的模型架构**（不只是 ExtraTrees，对不同字段用不同的模型）
4. **帧级建模**（当前是帧均值聚合，丢失了帧间变化信息）

对于某些字段，90% BA 可能在当前数据量下不可能达到：
- hemorrhage 阳性仅 12 例 → 二分类 BA 天花板受限于阳性召回，12 例中错 2 个就掉 8pp
- crossing_ratio/malformation_ratio 少数类 ≤ 5 例 → 序数分类在极端不平衡下 BA 很难高
对这些字段，如实报告当前能达到的最高 BA 和数据量限制，不虚报。

# 推荐攻击方向（按预期回报排序）

**方向 A：分割特征（最大未开发资源）**
用 2,332 对 mask 训练轻量分割网络（如 SegFormer-B0）→ 冻结 → 对 582 张分类图推理 → 提取 encoder 中间层特征（比 DINOv2 mean 信息更丰富）→ 拼入下游分类器。
预期：分割 encoder 能提供像素级血管结构信息，DINOv2 只有图像级语义。

**方向 B：DINOv2 微调或 adapter**
在 2,332 张分割图上做 DINOv2 LoRA/adapter 微调（分割任务），让视觉表示对血管结构更敏感 → 冻结 → 重新提取 embedding → 下游分类器。
预期：v1 用的是 ImageNet 预训练的 DINOv2 特征，对甲襞微循环不够专业化。

**方向 C：帧级建模替代帧均值**
当前所有字段都是帧均值聚合。改为：
- 每帧独立预测 → attention pooling 或 gated MIL 聚合病例级预测
- 或者 Transformer 对帧序列建模
预期：帧均值丢失了"哪些帧有关键信息"的信号。

**方向 D：任务专用模型架构**
- clarity/blood_color：序数回归（CORAL/CORN）替代分类
- exudation/hemorrhage：MIL + focal loss
- 形态字段：从检测框直接计数而不是分类
- papilla/SVP：如果无法到 90%，分析是否因为标签本身噪声大

**方向 E：错误分析驱动的迭代**
对每个字段的 OOF 错误样本：
- 可视化错误病例的帧
- 统计错误集中在哪些类别/帧质量/病例特征
- 针对性设计特征或模型改进

**方向 F：外部预训练**
搜索公开血管分割/甲襞微循环数据集，在更大数据上预训练特征提取器，然后迁移到本项目。
