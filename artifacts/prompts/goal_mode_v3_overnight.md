# 推荐的起步方向（不是固定步骤，是建议的优先尝试顺序）

你可以按任何顺序执行，也可以根据中间结果调整方向。但以下是基于 v1 瓶颈分析的高回报方向：

**方向 A：分割驱动的新特征**
用 2,332 对 mask 训练 U-Net/SegFormer → 冻结 → 对 582 张分类图推理提取帧级血管特征 → 拼入下游分类器。这直接解决"v1 只有粗粒度分割统计"的瓶颈。

**方向 B：检测驱动的新特征**
用 671 张标注图微调 YOLOv8 → 冻结 → 对分类图推理 → 提取帧级检测特征（框数、类别分布、置信度）。这为形态字段（count/crossing/malformation）提供实例级信号。

**方向 C：pooling 改进**
用帧质量评分加权聚合，或 top-k 聚合。这是最快能跑出结果的方向，但必须基于新特征（不是只改 v1 的聚合方式）。

**方向 D：稀疏病灶 MIL**
对 exudation/hemorrhage 做 frame-level MIL + top-k pooling + focal loss。这些字段的瓶颈是均值池化淹没局灶信号，MIL 是直接对应的解法。

**方向 E：模型架构升级**
如果新特征 + ExtraTrees 到顶了，尝试 LightGBM、CatBoost、简单 MLP、或对 DINOv2 做 LoRA 微调。

**方向 F：外部知识**
如果以上都不行，搜索论文和开源方案，看类似任务（甲襞微循环、视网膜血管、皮肤镜）的最新方法，适配到本项目。
