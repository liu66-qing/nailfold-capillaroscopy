# expert-router-final 交付证据

本包整理既有结果并从保存的折外预测复算；没有重训、没有新增测试、没有读取原始图像或重新预测原47例。

## 版本与入口

- 推理代码提交：`66314f2457ef207fbc7e6073c6a181c32eaa0101`。
- 发布版：`expert-router-final`；权重：`expert_router_v1`；API：`final_api.py`；推理：`final_inference.py`。
- 训练：233例检查；20个二分类目标，组合为20行输出（包含4个固定行、1个派生行）。此前说明中的“13个二分类目标”与当前注册表不一致，以本次数量为准。
- DINOv2-B、颜色统计、分割几何、检测特征四路等权融合，Platt校准；四个核心权重已核对SHA256。

## 证据边界

- 独立锁定集：没有。原47例已进入全量训练；下述原locked子集结果属于交叉验证子集描述，不能称独立测试。
- 现有5折内部验证含折内校准；经多轮探索，指标可能乐观。分割器等上游监督是否对每个外层折隔离未在本次重新审计，不能认定为完整端到端无泄漏验证。
- 单位是检查病例；病人身份未核实，不沿用“病人级”表述。
- 现有LOAO见 `../artifacts/experiments/expert_routes_20260928/router_loao.csv`：ALL臂使用p>训练阳性率；发布版用校准q>0.5，因此不作为发布规则匹配的LOAO成绩。
- 固定行不使用图像；派生行无独立评估。置信等级不等于拒答，当前发布版仍输出这些行。
- 本包不证明健康建议有效性、外部泛化或可上线。
