## 检查命令

```bash
python scripts/verify_handoff.py
python scripts/verify_handoff.py --check-models
python -m pytest tests -q
```

verify_handoff只用Python标准库和Git，检查本地文档的文件链接（不检查锚点）、资源及指标来源哈希、字段定义、混淆矩阵、保存的OOF决策和47例指标一致性。加--check-models时检查5个模型资产。

测试需要requirements及pytest/httpx。涉及本地模型和训练特征的测试缺资产时显示SKIPPED；不能把跳过称为通过。34项测试在维护者完整本地环境通过；仅包含已交付源码的隔离副本运行最终版测试为6项通过、9项因缺模型而跳过。隔离副本仍复用维护者Python环境，不等于全新依赖安装验证，也不意味着已包含训练数据或临床准确率得到验证。
